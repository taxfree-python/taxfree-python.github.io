[TypeSafe AI][typesafe] の Jev は、同社が System One Model と呼ぶモデルで、最近やたら TL で見るので科学系の多肢選択ベンチで検証しました。[公式ドキュメント][sdk-docs]曰く "System One models are built to make fast, structured decisions that software can use directly. No text generation, no parsing." で、"Decisions, not strings" らしいです。state (状況を表す任意の JSON) に対して choice / noul / score の型を持つ question を評価し、選択肢ごとの確率と confidence を返します。

<!--more-->

## 呼び出し方

API は公式 endpoint の `POST https://api.typesafe.ai/v1/systemone` に `state` と `questions` を投げる形です。OpenRouter のようなサービスは経由せず、直接叩いています。公式の Python SDK `typesafe-sdk` ([ドキュメント][sdk]、[GitHub][sdk-repo]) を使うと次のようになります。

```python
from typesafe_sdk import AsyncTypeSafeClient, Choice

client = AsyncTypeSafeClient()  # TYPESAFE_API_KEY

response = await client.system_one(
    state={
        "question": "In a parallel universe where a magnet can have an "
                    "isolated North or South pole, Maxwell's equations "
                    "look different. But, specifically, which of those "
                    "equations are different?",
        "options": {
            "A": "The one related to the circulation of the magnetic "
                 "field and the flux of the electric field.",
            "B": "The ones related to the divergence and the curl of "
                 "the magnetic field.",
            "C": "The one related to the divergence of the magnetic field.",
            "D": "The ones related to the circulation of the electric "
                 "field and the divergence of the magnetic field.",
        },
    },
    questions={
        "answer": Choice(
            instructions=(
                "`question` is a graduate-level science question and "
                "`options` contains the candidate answers A, B, C and D. "
                "Which option is the correct answer to `question`?"
            ),
            criteria={"A": ..., "B": ..., "C": ..., "D": ...},
        ),
    },
    model="jev-latest",
)

answer = response.answers["answer"]
# answer.choice        -> "D"
# answer.probabilities -> {"D": 0.79, "C": 0.15, "B": 0.06, "A": 0.0}
# answer.confidence    -> 0.72
```

問題文と選択肢は加工せずそのまま `state` に入れ、`criteria` にも同じ選択肢の dict を渡します。応答の `probabilities` の argmax を回答とし、複数選択問題では確率の上位 N 個を選んで正解集合との完全一致で採点しました (部分点なし)。二値分類には `Choice` ではなく `Noul` を使っています。

Jev はテキストのみに対応するため、画像が必須の問題はロード時に除外しました。モデルは `jev-latest` を指定し、応答の `model` フィールドは `jev-1.13.0` でした。計測日は 2026-09-19 です。

図 1. ベンチマークごとの accuracy。バー上の縦線は chance level で、問題ごとの選択肢数 $k$ から $1/k$ (N 個選ぶ複数選択では $1/\binom{k}{N}$) を求めて平均した値。
